## 🧠 Learning Architecture

Every major topic is developed across three parallel tracks:

- **Track A — Core Theory:** first-principles understanding, mental models, language semantics, runtime behavior, and specification-level reasoning.
- **Track B — Implementation:** guided coding → independent implementation → debugging → production hardening.
- **Track C — Interview / Reasoning:** retrieval → output prediction → debugging → trade-offs → architecture → principal-level judgment.

### Depth Progression

**Intuition → Syntax → Practical Usage → Edge Cases → Runtime / Internals → Specification → Performance / Security → Production → Interview / Reasoning → Principal Judgment**

### Mastery Gate

**Understand → Explain → Predict → Implement → Debug → Apply → Compare → Defend**
