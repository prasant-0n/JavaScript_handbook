# JavaScript Mastery

> **Principal Engineer → Platform Engineer Track · 150 Chapters · Modular Markdown Curriculum**

A structured, production-oriented JavaScript curriculum designed to take a developer from language fundamentals through ECMAScript semantics, runtime internals, browser and Node.js platforms, production engineering, system design, and principal-level assessment.

The curriculum is intentionally maintained as **individual Markdown chapter files** so concepts can be studied, expanded, reviewed, revised, and assessed independently.

## 🎯 Goals

- Build deep JavaScript fundamentals rather than framework-only knowledge.
- Understand the difference between **ECMAScript language semantics**, runtime behavior, browser APIs, Node.js APIs, and engine implementation details.
- Develop strong mental models for execution, memory, asynchronous behavior, objects, modules, networking, and performance.
- Connect theory to implementation, debugging, production engineering, and system design.
- Prepare for senior/principal-level JavaScript and backend engineering interviews.

## 🧠 Learning Model

### Track A — Core Theory
First-principles understanding, language rules, mental models, ECMAScript semantics, runtime behavior, and specification concepts.

### Track B — Implementation
Code examples, guided implementation, independent implementation, edge-case handling, debugging, and production hardening.

### Track C — Interview & Engineering Reasoning
Output prediction, debugging, comparisons, trade-offs, architecture decisions, scenario analysis, and senior/staff/principal-level reasoning.

### Depth Progression

**Intuition → Syntax → Semantics → Runtime → Internals → Specification → Performance/Security → Production → Interview → Principal Judgment**

## 🏆 Mastery Gate

A chapter is not considered mastered merely because it has been read.

**Understand → Explain → Predict → Implement → Debug → Apply → Compare → Defend**

2. Treat `javascript-mystry.md` as the canonical curriculum index.

4. Keep each chapter as an independently maintainable Markdown document.
