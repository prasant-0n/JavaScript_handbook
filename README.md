# JavaScript Handbook

> **Principal Engineer Track · 122 Chapters · Modular Markdown Curriculum**

## 🎯 Purpose

This repository is a structured, production-oriented JavaScript mastery curriculum designed to progress from language fundamentals to runtime internals, browser and Node.js platforms, production engineering, system design, and principal-level assessment.

The curriculum is split into individual Markdown chapter files so every topic can be studied, expanded, reviewed, and maintained independently without creating one oversized document.

### Quick Start

1. Open the **[Master Curriculum Index](./javascript-mastery-index.md)**.
2. Choose a chapter from the roadmap.
3. Click the chapter title to open its Markdown file.
4. Study it using **Theory → Implementation → Interview / Reasoning**.
5. Continue through the curriculum in numerical order.

## 🧠 Learning Model

- **Track A — Core Theory:** first-principles understanding, mental models, language/runtime semantics, and specification behavior.
- **Track B — Implementation:** practical coding, guided implementation, independent implementation, debugging, and production hardening.
- **Track C — Interview / Reasoning:** output prediction, trade-offs, debugging reasoning, design questions, and principal-level judgment.

### Depth Progression

**Intuition → Syntax → Practical Usage → Edge Cases → Runtime / Internals → Specification → Performance / Security → Production → Interview / Reasoning → Principal Judgment**

## 🏆 Mastery Gate

**Understand → Explain → Predict → Implement → Debug → Apply → Compare → Defend**
